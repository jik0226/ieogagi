# 이어가기 설계 문서 색인

기획서 ❷ 4·5절(아키텍처·데이터 모델)과 구현을 함께 보는 문서 모음이다. 기준은 2026-10-11 저장소 상태(보안 리뷰 조치 커밋 `cd57f76` 포함)이고, 코드와 다르면 코드가 맞다.

- [아키텍처.md](아키텍처.md): 3계층 구조, 배포 토폴로지, 요청 파이프라인(미들웨어 순서·인가·감사 시퀀스), 로그인 흐름, 모듈 의존 규칙, 기획서와의 차이.
- [ERD.md](ERD.md): 테이블 9개의 ER 다이어그램, 제약·인덱스, 앱 DB 역할의 테이블·컬럼 단위 권한, 데이터 수명주기(파기·세션·초대·기록·감사), 기획서와의 컬럼 단위 차이.
- [../API_설계.md](../API_설계.md): 27개 API 계약과 역할별 권한 매트릭스. 스키마의 정본은 [../api/openapi.json](../api/openapi.json)이다.
- [wireframes.html](wireframes.html): 화면 6개의 와이어프레임과 화면 흐름도.
- [img/](img/): wireframes.html을 캡처한 PNG(W1~W6, flow, states).
- [../보안설계.md](../보안설계.md): 보안 기법 25개, 독립 보안 리뷰 15건과 조치, 설계 결정 기록.
- [../화면목록.md](../화면목록.md): 화면 ID(S1~S6)별 동작, 민감정보 확인 흐름, 오류 문구 정책.
